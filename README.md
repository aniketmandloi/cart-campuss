# Cart Campuss

A planned public car discovery and buying-research app with an India purchase-cost context.

Start with the [implementation spec issue](https://github.com/aniketmandloi/cart-campuss/issues/9), its [repository copy](docs/specification.md), and the [domain glossary](GLOSSARY.md). The [closed decision map](https://github.com/aniketmandloi/cart-campuss/issues/1) preserves the planning history.

This repository currently contains planning documents and a design concept. Application implementation follows the specification's delivery sequence.
